# موقع سفراء NextStep AI

الملفات:
- `index.html` — صفحة الطلاب (الشرح، الشروط، نموذج التسجيل). هذا الرابط الذي يُنشر مع الإعلان.
- `admin.html` — لوحة الأدمن (كلمة مرور): فرز الطلبات + طباعة بطاقات السفراء. لا تنشر رابطها.
- `supabase.sql` — إنشاء الجدول والصلاحيات ومخزن الصور.

## الإعداد (مرة واحدة)
1. **Supabase ← SQL Editor:** الصق محتوى `supabase.sql` واضغط Run.
2. **Authentication ← Users ← Add user:** أنشئ مستخدماً ببريد الأدمن (`nextstepai12@gmail.com`) وكلمة المرور التي تريدها، وفعّل Auto Confirm. ثم من Authentication ← Sign In / Providers أطفئ تسجيل المستخدمين الجدد.
3. **Project Settings ← API Keys:** انسخ المفتاح العام (Publishable / anon key) والصقه مكان `PASTE_PUBLISHABLE_KEY_HERE` في أعلى سكربت الملفين (`index.html` و`admin.html`). هذا المفتاح آمن للنشر، أما المفتاح السري (secret/service_role) فلا تضعه أبداً.
4. **وقت الإغلاق:** في `index.html` غيّر `CLOSE_AT`، وفي `supabase.sql` غيّر التاريخ داخل سياسة `students can apply` (بالتوقيت العالمي) ليتطابقا. يمكنك تعديل السياسة لاحقاً من Authentication ← Policies.
5. **النشر:** ارفع الملفين على أي استضافة ثابتة (Vercel أو Netlify أو GitHub Pages) أو افتحهما محلياً للتجربة.

## الاستخدام
- **الفرز:** ادخل `admin.html` بكلمة المرور، غيّر حالة كل طلب (جديد / قيد الفرز / مدعو للمقابلة / مقبول / مرفوض)، وصدّر الجدول إلى Excel.
- **البطاقات:** تبويب «بطاقات السفراء» ← «جلب المقبولين» أو «استيراد Excel» (عمودان: الاسم، الجامعة) ← عدّل الاسم أو الصورة إن لزم ← طباعة. اختر في نافذة الطباعة «حفظ كـ PDF» والهوامش «بلا» وفعّل «الرسومات الخلفية».
- مقاس البطاقة القياسي 54×86 مم. خيار الورقة A4 يطبع 9 بطاقات؛ للطباعة على وجهين اختر «قلب على الحافة الطويلة».
